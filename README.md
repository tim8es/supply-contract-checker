# Supply Contract Checker

Минимальный прототип проверки действующих условий договоров поставки.

**Архитектура:** GitHub Pages (статический UI) → JS-парсер TXT в браузере → группировка по номеру договора → применение только подписанных допсоглашений, вступивших в силу к дате проверки → таблица + дословные цитаты и переход к строкам исходного текста.

**GitHub Actions:** автоматические тесты и публикация сайта. Это не HTTP-сервер; для интерактивного API требуется внешний слой, например работающий n8n. Запуск небольшой модели на runner допустим как дополнительный асинхронный этап, но не нужен для базовых шести TXT.

**Результаты на 10.03.2026:** STN-101 — 1 380 000 ₽ и 30.04.2026; STN-102 — 840 000 ₽ и 20.03.2026; STN-103 — сумма «нет данных», срок 30.04.2026. STN-102 предлагает перенести поставку на 27.03.2026, STN-101 имеет неподписанный проект — оба не меняют действующих условий.

**Контракты данных:** Document(name,id,kind,signed,effective,lines); Field(value,evidence{file,line,quote},changedBy); Contract(id,supplier,amount,deadline,proposals,review,documents). Пропуски = null; изменять значение вправе только подписанное и вступившее в силу дополнительное соглашение.

**Три компромисса:** правила вместо LLM (детерминизм вместо охвата всех формулировок); обработка браузером (нет backend и общего хранилища); Pages + Actions (дешевое развёртывание, но нет синхронных вебхуков).

**Масштабирование:** при 100 000 документов понадобятся отдельные ingest API/очереди, объектное хранилище, PostgreSQL с версионированием, права доступа на документ и фрагмент, аудит, воркеры и человек в контуре проверки. GitHub Actions перестанет быть основным вычислительным слоем.

**Разработка:** Node.js >=20, без npm-зависимостей, тесты через `npm test`. После появления файлов интерфейса запустить `python3 -m http.server 8080` и открыть localhost:8080. Для Pages выбрать Settings → Pages → Source: GitHub Actions.

**Ограничения:** только учебные UTF-8 TXT с узнаваемыми формулировками, не проверяет подлинность подписей, PDF/OCR и авторизация не реализованы. Реальные конфиденциальные договоры нельзя коммитить в публичный репозиторий.

Продуктовая записка, тесты и исходники входят в локальный архив MVP.
